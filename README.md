## ✧ The Story

> **Not just another portfolio. A place for things worth making.**

**AMSOULNESS / ASLNS** is my corner of the internet: part personal portfolio, part creative laboratory, and part collection of practical web utilities.

I built it around a simple idea: **software can be useful *and* feel memorable.** Every screen is an opportunity to balance function, motion, clarity, and visual expression.

This repository brings together two connected experiences:

- **The Portfolio** — the person, the projects, the skills, and the creative journey behind the code.
- **The Tools Hub** — eight browser-based utilities for everyday creative and developer tasks.

## 🚀 Run It Yourself

Want to explore the code, customize a component, or experiment with the design? Start here.

**Prerequisites:** Node.js compatible with Vite 8 and npm.

```bash
# 1. Clone the project
git clone https://github.com/amsoulness/portfolio.git

# 2. Enter the directory
cd portfolio

# 3. Install dependencies from the lockfile
npm ci

# 4. Launch the development server
npm run dev
```

Open the local address printed by Vite, typically **http://localhost:5173**.

### Developer Commands

| Command | Action |
| :--- | :--- |
| `npm run dev` | Launch the development server |
| `npm run build` | Type-check and build the production site |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint checks |

<details>
<summary><b>🛠️ Build and deployment notes</b></summary>
<br />

Build the site with:

```bash
npm run build
```

Vite writes the production output to `dist/`. The website is deployed on **Vercel** using the Vite build setup. The repository includes `vercel.json` for client-side routing, including `/tools`.

For a new Vercel project, import the GitHub repository, use the **Vite** preset, set the build command to `npm run build`, and set the output directory to `dist`.

</details>
